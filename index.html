Maintainer tool

DiffDocket

Turn a pull request into a structured review packet that is easy to scan, easy to share, and hard to misread.

GitHub README
Sample receipt Markdown 
# DiffDocket Receipt
- Risk level: medium
- Changed files: src/app.py, tests/test_app.py
- Test gap: none
- Release note: source and test updates

What it does

DiffDocket reads a git diff, classifies the change set, and emits a concise review receipt in Markdown or JSON. No external service is required.

Why it matters

Maintainers need a fast, repeatable way to see risk, tests, and release impact before they merge.

Where it lives

Hosted at diffdocket.vercel.app, source on GitHub, designed to stay public and easy to audit.
